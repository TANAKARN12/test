# Welcome Hub & Digital Pass
เว็บแอปสำหรับงานประชุมวิชาการและ AGM 2026 — mobile-first, ไม่ต้อง build, ไม่ต้องมี backend/server

สร้างด้วย HTML/CSS/JavaScript ล้วน (ไม่ใช้ React/Next.js) อ่านข้อมูลกำหนดการจาก **Google Sheet ที่เผยแพร่สู่เว็บ (Publish to web)** โดยตรงจากฝั่งเบราว์เซอร์ ไม่ต้องมี server หรือ API key ใดๆ

---

## 1. โครงสร้างไฟล์

```
welcome-hub/
├── index.html          ← หน้าเว็บหลัก
├── manifest.json        ← ตั้งค่า "เพิ่มลงหน้าจอโฮม" (PWA)
├── sw.js                 ← service worker (ทำให้ใช้งานออฟไลน์ได้)
├── css/styles.css        ← ดีไซน์ทั้งหมด (โทนกรมท่า-ทอง ของสภาฯ)
├── js/config.js          ← ★ ไฟล์เดียวที่ต้องแก้ไขข้อมูลงาน ★
├── js/sheet-data.js       ← ตัวดึงข้อมูลจาก Google Sheet
├── js/app.js              ← ตรรกะแอปทั้งหมด
└── icons/logo.png         ← โลโก้สภาฯ (ไฟล์ตัวอย่าง แทนที่ด้วยโลโก้จริง)
```

## 2. ตั้งค่า Google Sheet (แหล่งข้อมูลกำหนดการ)

1. สร้าง Google Sheet ใหม่ ตั้งชื่อชีต (tab) ว่า **`Agenda`**
2. ใส่หัวตารางแถวแรกตามนี้ (สะกดตามนี้เป๊ะๆ):

   | Day | Order | Time  | EndTime | Title              | Speaker      | Type     | Room    | PDFFileID |
   |-----|-------|-------|---------|--------------------|--------------|----------|---------|-----------|
   | 1   | 10    | 09:00 | 09:30   | พิธีเปิด           |              | ceremony |         |           |
   | 1   | 20    | 09:30 | 10:30   | ปาฐกถาพิเศษ...     | ศ.ดร....     | keynote  |         | 1AbCxyz   |
   | 1   | 30    | 13:00 | 14:30   | หัวข้อห้อง A       | อ....        | parallel | ห้อง A  | 1DeFghi   |
   | 1   | 30    | 13:00 | 14:30   | หัวข้อห้อง B       | อ....        | parallel | ห้อง B  |           |
   | 1   | 30    | 13:00 | 14:30   | หัวข้อห้อง C       | อ....        | parallel | ห้อง C  |           |

   **กติกาสำคัญ:**
   - `Day` = `1` หรือ `2`
   - `Order` = ตัวเลขเรียงลำดับ (กันปัญหาการเรียงเวลาแบบข้อความ)
   - `Type` = `keynote` / `plenary` / `parallel` / `break` / `ceremony`
   - แถวที่มี **`Time` และ `EndTime` ตรงกัน + `Type = parallel` หลายแถว** ระบบจะรวมเป็น **แท็บย่อยตามห้องอัตโนมัติ** (ไม่ต้องเขียนโค้ดเพิ่ม แค่เพิ่มแถวใน Sheet)
   - `PDFFileID` = เอา "File ID" จากลิงก์แชร์ไฟล์ Google Drive (ดูขั้นตอนข้อ 3) เว้นว่างได้ถ้าไม่มีเอกสาร

3. **เผยแพร่สู่เว็บ**: เมนู `File` → `Share` → `Publish to web` → เลือกชีต `Agenda` → กด `Publish`
   *(ขั้นตอนนี้จำเป็น ถ้าไม่ทำจะดึงข้อมูลไม่ได้)*
4. คัดลอก **Sheet ID** จาก URL ของ Sheet:
   `https://docs.google.com/spreadsheets/d/`**`ตรงนี้คือ SHEET_ID`**`/edit`
5. นำ SHEET_ID ไปใส่ใน `js/config.js` → `sheet.id`

## 3. ตั้งค่าเอกสาร PDF (Google Drive)

1. อัปโหลดไฟล์ PDF นำเสนอขึ้น Google Drive
2. คลิกขวาไฟล์ → `Share` → เปลี่ยนเป็น **"Anyone with the link" / "ทุกคนที่มีลิงก์" → Viewer**
   *(สำคัญมาก — ถ้าไม่เปิดสิทธิ์นี้ ผู้เข้าร่วมจะเปิดไฟล์ไม่ได้)*
3. คัดลอก **File ID** จากลิงก์แชร์:
   `https://drive.google.com/file/d/`**`ตรงนี้คือ FILE_ID`**`/view?usp=sharing`
4. นำ FILE_ID ไปใส่ในคอลัมน์ `PDFFileID` ของแถวนั้นๆ ใน Google Sheet

## 4. ตั้งค่าแบบประเมิน (Google Form) + เกียรติบัตร

1. สร้าง Google Form แบบประเมินตามปกติ
2. คัดลอกลิงก์แบบฟอร์ม (ปุ่ม Send → ไอคอนลิงก์) แล้วเติม `?embedded=true` ต่อท้าย ใส่ใน `js/config.js` → `evaluation.formEmbedUrl`
3. ใส่ลิงก์เกียรติบัตร (ไฟล์เดียวสำหรับทุกคน หรือโฟลเดอร์ Drive ที่แชร์แบบดูได้) ใน `certificate.downloadUrl`

**ข้อจำกัดที่ควรทราบ:** เนื่องจากไม่มี backend เว็บแอปนี้**ตรวจสอบการส่งแบบฟอร์มจริงไม่ได้อัตโนมัติ** (ข้อจำกัดของ Google Form ที่ฝัง iframe ข้ามโดเมน) จึงใช้วิธีให้ผู้เข้าร่วมกดปุ่ม **"ฉันตอบแบบประเมินเรียบร้อยแล้ว"** เพื่อปลดล็อกเกียรติบัตรเอง — เพียงพอสำหรับงานทั่วไปที่ไม่ต้องการความเข้มงวดสูง

> **อัปเกรดในอนาคต (ถ้าต้องการความแม่นยำ 100%):** เปลี่ยนไปใช้ Google Apps Script เป็น backend เบาๆ (แบบเดียวกับระบบสั่งซื้อสินค้าของสภาฯ) เพื่อตรวจสอบยืนยันการส่งฟอร์มจริงและออกเกียรติบัตรแบบระบุชื่อผู้เข้าร่วมได้อัตโนมัติ

## 5. แก้ไขข้อมูลงาน + สีแบรนด์

เปิด `js/config.js` แก้เฉพาะค่าฝั่งขวาของ `:` — ชื่องาน วันที่ สถานที่ ลิงก์ต่างๆ
โลโก้: แทนที่ไฟล์ `icons/logo.png` ด้วยโลโก้จริงของสภาฯ (แนะนำขนาดสี่เหลี่ยมจัตุรัส พื้นหลังโปร่งใสหรือขาว)

สีแบรนด์ (แก้ได้ที่ต้นไฟล์ `css/styles.css` ในส่วน `:root`):
- กรมท่าเข้ม (หลัก): `#0E2A47`
- ทอง (เน้น/พิธีการ): `#C9A24B`
- ครีมไอวอรี (พื้นหลัง): `#FBF7EE`

## 6. ทดสอบก่อนขึ้นจริง

เปิดเทอร์มินัลในโฟลเดอร์นี้แล้วรัน (ไม่ต้องติดตั้งอะไรเพิ่ม ถ้ามี Python):

```
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000` ในเบราว์เซอร์ (ทดสอบผ่านมือถือจริงจะแม่นยำที่สุด)

## 7. Deploy ขึ้นใช้งานจริง (ฟรี — GitHub Pages)

1. สร้าง repository ใหม่บน GitHub เช่น `swpc-welcome-hub`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo (push จาก git หรือ upload ผ่านเว็บก็ได้)
3. ไปที่ repo → `Settings` → `Pages` → เลือก branch `main` / โฟลเดอร์ `/ (root)` → `Save`
4. รอสักครู่ จะได้ลิงก์ `https://<username>.github.io/swpc-welcome-hub/`
5. นำลิงก์นี้ไปทำ QR Code แจกหน้างานได้เลย

## 8. หมายเหตุเรื่องการใช้งานออฟไลน์

แอปนี้แคชหน้าเว็บและกำหนดการล่าสุดที่เคยโหลดไว้ในเครื่อง ผ่าน Service Worker + localStorage ดังนั้น:
- เปิดแอปครั้งแรก **ต้องมีอินเทอร์เน็ต** (เพื่อโหลดข้อมูลจาก Sheet ครั้งแรก)
- หลังจากนั้นถึงแม้สัญญาณขาดหาย ก็ยังเปิดดูกำหนดการ/เอกสารที่เคยโหลดไว้ได้ (จะมีข้อความ "แสดงข้อมูลที่บันทึกไว้ (ออฟไลน์)" กำกับ)
- แบบประเมิน (Google Form) ต้องใช้อินเทอร์เน็ตเสมอ เนื่องจากเป็นการฝังหน้าเว็บของ Google โดยตรง
